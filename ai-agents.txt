# Agentii Investment Intelligence — ai-agents.txt

This file documents protocols that third-party MCP clients and AI agents MUST follow when interacting with the agentii MCP server at `https://mcp.agentii.ai/mcp`.

## Authentication

All calls require an `AGENTII_API_KEY` via `Authorization: Bearer ${AGENTII_API_KEY}` or `X-API-Key: ${AGENTII_API_KEY}` header.

## MCP Server

- URL: `https://mcp.agentii.ai/mcp`
- Transport: HTTP (POST `tools/call`, GET `tools/list`, POST `initialize`)
