# fda-catalyst-medicines — Analyst Mode Definitions

Derived from the skill's ## Modes section (spec 046 M1).

### Mode: watchlist

**Objective**: One dated catalyst calendar with per-ticker sections, sorted by date.

### Mode: single-target

**Objective**: Full event timeline for one ticker with per-event probability framing and exclusivity state.

### Mode: event-type

**Objective**: Restrict coverage to one event class — PDUFA, AdCom, label expansion, or biosimilar milestones.

### Mode: exclusivity-scan

**Objective**: Orange Book and 180-day exclusivity windows as the launch-timing lens.
