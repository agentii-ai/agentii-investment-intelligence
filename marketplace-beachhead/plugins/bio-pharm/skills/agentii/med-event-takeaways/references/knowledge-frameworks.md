# Med Event Takeaways — Knowledge Frameworks

Static grounding for `med-event-takeaways` (spec 055). Runtime records (approved med strategies/cases) are retrieved via the knowledge tools and cited with /v/ URLs; this file carries the event-note anatomy and conflict-handling methodology. All content is an original paraphrase of publicly taught sell-side note-writing practice.

## The Note Anatomy

Nine beats, in order:

1. **Headline verdict** — paragraph one states what the event means in 2-3 sentences.
2. **Per-stock takeaways** — each covered name gets 2-4 lines with at least one model number.
3. **KOL/event distillation** — themes condensed from the sessions, with conflicting views surfaced verbatim.
4. **Raw data + cross-trial comparison lattices** — the numbers as presented, placed against standard-of-care and class peers.
5. **Modeled deltas vs consensus** — unadjusted peak sales × POS, compared to consensus explicitly.
6. **Three what's-changed vectors** — estimates / thesis / positioning per name.
7. **Upside/downside risk bullets**.
8. **Living-tracker links** — pointers to the weekly track and diff products the note should update.

## The Three What's-Changed Vectors

- **Estimates** move first — numbers change before narratives.
- **Thesis** moves second — the narrative adjusts to the numbers.
- **Positioning** moves last — ratings and portfolio stances are the slowest variable.
- A note that updates positioning without touching estimates is out of order; the slot-refresh discipline is explicit about which vector moved.

## Conflict Materiality

- Conflicting characterizations of the same data are surfaced **verbatim** — both views, with their speakers.
- Each conflict is then **rated by materiality** ("incremental positive, not narrative-changing") or **deferred** to a larger outcomes trial when the sample or design cannot settle it.
- Conflicts are never silently averaged; an unresolved conflict stays flagged as unresolved.

## Uncertainty Discipline

- Scenario-flexing at market level; probability-of-success at asset level.
- POS changes are logged with reasons — a moved probability without a reason is a defect.
- Model-vs-consensus delta is always explicit; where a likelihood is unquantifiable, abstain explicitly ("no view on likelihood") rather than imply precision.

## The Buy-Side Lens

- Include a client-question section ("one common question we have received…") where investor attention sits.
- Track where investor attention is concentrated across the covered names — attention and model impact are different vectors.
- Give per-name bull/bear pivot conditions: the stated condition under which the stance flips.

## Living-Tracker Convention

- Event notes link to the living trackers (weekly commercial track, trial status diff) rather than duplicating them.
- Exhibits and trackers are **append-only**: new observations append, prior entries are never rewritten.
- Every fact in the note carries a source line; derived arithmetic carries `[DEDUCTED]`, judgments `[VIEW]`.

## Modality Notes

- **Drugs/biologics**: readout-centric events; persistence and titration data feed the model.
- **Devices**: procedural adoption, utilization, and ASP commentary dominate device events.
- **Vaccines**: ACIP discussion, cohort scope, and procurement signals are the event-relevant content.
