# us5_peer_analog — launch-analog peer matching (peer-bench-med)

## Prompt

Select peers for a recently launched drug: apply same-class and same-channel launch-analog matching, score mechanism overlap via the drug-knowledge reverse lookups, and show provenance on any conflicting source values.

## Rubric Checks

- [ ] Same-class + same-channel analog matching applied
- [ ] Mechanism-overlap score computed from reverse lookups
- [ ] Conflicting source values shown with provenance
- [ ] No peer selected without a stated criterion
