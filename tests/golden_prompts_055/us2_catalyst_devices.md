# us2_catalyst_devices — device decision calendar (fda-catalyst-devices)

## Prompt

Build the device-decision calendar for a med-device ticker: enumerate PMA/De Novo/510(k) decisions, coverage/NTAP milestones, and any recall or watch action treated as a risk signal.

## Rubric Checks

- [ ] 510(k)/PMA/De Novo pathway named correctly per event
- [ ] Coverage/NTAP milestones listed where retrievable
- [ ] Recall/watch actions surfaced as risk signals with dates
- [ ] No script-based metric used for a device
