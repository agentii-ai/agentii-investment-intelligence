# us4_readout_lattice — cross-trial readout evaluation (trial-readout-analysis)

## Prompt

Evaluate a Phase 3 readout: build the cross-trial comparison lattice against SoC and class peers, weigh tolerability/persistence alongside efficacy, and if a safety imbalance appears, state whether it defers to a larger outcomes trial.

## Rubric Checks

- [ ] Cross-trial lattice vs SoC + ≥2 class peers
- [ ] Tolerability/persistence treated as co-equal axis
- [ ] Safety-imbalance deferral rule applied
- [ ] Conflicting views rated by materiality, not averaged
