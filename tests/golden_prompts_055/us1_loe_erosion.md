# US1 — LOE / Biosimilar Erosion Series

## Prompt

Run the market-share-tracking skill on a branded biologic that now faces biosimilar entry and produce the LOE erosion series: the branded YoY decay (weekly/4-wk/12-wk) side by side with the entrant share series, with the entrant's approval and launch dates marked on the timeline. Show previous values next to new values for every delta, and attach per-row caveats (or coverage_gap) wherever the underlying script data is restricted, rounded, or mixed.

## Rubric

- [ ] Branded YoY decay series present across the three windows (weekly / 4-wk / 12-wk)
- [ ] Entrant share series presented alongside, with approval and launch dates on the timeline
- [ ] Previous values shown next to new values on every delta
- [ ] Restricted/rounded/mixed data carries caveat annotations or coverage_gap; derived share labeled [DEDUCTED]
- [ ] Zero fabricated script numbers; no share number offered while an IQVIA-style restriction is stated
- [ ] Modality vocabulary correct — biologics tracked in scripts/share/erosion terms, never conflated with device or vaccine metrics
