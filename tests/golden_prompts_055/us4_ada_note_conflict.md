# US4 — ADA-Style Event Note with a Conflicting-KOL Case

## Prompt

Write the med-event-takeaways note for a completed ADA conference covering a diabetes/obesity class: follow the professional note anatomy section-for-section (headline verdict → per-stock takeaways with model numbers → KOL distillation → cross-trial comparison lattices → modeled deltas vs consensus as unadjusted peak × POS → the three what's-changed vectors → risk bullets → living-tracker links). State model-vs-consensus deltas explicitly, and surface at least one conflicting KOL characterization of the same data verbatim with a materiality rating (or an explicit deferral to a larger outcomes trial).

## Rubric

- [ ] Note anatomy present section-for-section, in order, with no section stubbed or skipped
- [ ] Each covered name's takeaway contains ≥1 model number
- [ ] Model-vs-consensus delta stated explicitly, with peak × POS arithmetic and assumptions visible
- [ ] ≥1 conflicting KOL view surfaced verbatim (both readings, attributed) with a materiality rating or an explicit deferral to a larger outcomes trial — never silently averaged
- [ ] Three what's-changed vectors (estimates / thesis / positioning) present per covered name
- [ ] Zero fabricated citations; no copyrighted exhibit text; badges [FACT]/[DEDUCTED]/[VIEW] with the summary table
