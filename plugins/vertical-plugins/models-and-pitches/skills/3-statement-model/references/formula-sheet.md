# 3-Statement Model — Canonical Formulas

## Income Statement → Balance Sheet Linkage
```
Net Income (IS) → Retained Earnings (BS)
Retained Earnings(t) = Retained Earnings(t-1) + Net Income(t) - Dividends(t)
```

## Income Statement → Cash Flow Statement Linkage
```
Net Income (IS) → Operating Cash Flow starting point (CF)
D&A (IS) → Add-back in Operating CF
```

## Balance Sheet → Cash Flow Statement Linkage
```
ΔWorkingCapital = ΔCurrentAssets - ΔCurrentLiabilities (BS) → Operating CF
Capex = ΔPP&E + D&A (BS reconciliation) → Investing CF
ΔDebt = Debt(t) - Debt(t-1) (BS) → Financing CF
```

## Balancing Checks
1. **BS Balance**: Assets = Liabilities + Shareholders' Equity (within 1% tolerance)
2. **CF Tie-Out**: Ending Cash (CF) = Cash (BS current period)
3. **Retained Earnings**: RE(t) = RE(t-1) + NI(t) - Dividends(t)
4. **PP&E**: PP&E(t) = PP&E(t-1) + Capex(t) - D&A(t)
