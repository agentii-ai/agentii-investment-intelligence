# Earnings Preview Deck — Validation Checklist

Expanded version of `## Validation Gates` with per-gate remediation steps.

1. **slide count**: between 4 and 6
 - *Remediation*: If outside: refuse delivery.
2. **estimates slide**: includes consensus, high, low
 - *Remediation*: If missing: flag in Coverage Gaps.
3. **source footers**: every slide has standard agentii citation
 - *Remediation*: If any missing: refuse delivery.
4. **peer comparison**: has >= 3 peers
 - *Remediation*: If < 3: flag in Coverage Gaps.
