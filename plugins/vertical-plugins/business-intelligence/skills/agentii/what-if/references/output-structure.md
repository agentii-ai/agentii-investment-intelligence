# what-if — Output Structure

1. **Executive Summary** (≤200 words) — scenario overview, probability-weighted outcomes
2. **Base Case Assumptions** — baseline projections with rationale and citations
3. **Bear Case** — downside scenario with triggers, magnitude, duration
4. **Bull Case** — upside scenario with catalysts, magnitude, probability
5. **Sensitivity Matrix** — key-driver sensitivity table (revenue growth × margins)
6. **Probability-Weighted EV** — probability × scenario value with ranges
7. **Key Metrics** — scenario comparison table, historical vs projected
8. **Coverage Gaps & Citations** — data not retrievable + citation index
