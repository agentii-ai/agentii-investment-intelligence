# unit-economics — Output Structure

1. **Executive Summary** (≤200 words) — unit economics health, LTV/CAC ratio, margins
2. **Customer Acquisition** — CAC estimation, payback period, sales efficiency
3. **Customer Lifetime Value** — LTV estimation, retention/churn analysis
4. **Unit Profitability** — gross margin per customer/unit, contribution margin
5. **LTV/CAC Analysis** — ratio trends, cohort performance, benchmark comparison
6. **Key Metrics** — CAC, LTV, churn rate, ARPU, gross margin per unit
7. **Coverage Gaps & Citations** — data not retrievable + citation index
