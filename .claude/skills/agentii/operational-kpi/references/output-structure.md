# operational-kpi — Output Structure

1. **Executive Summary** (≤200 words) — operational health snapshot, key trends
2. **Headcount & Productivity** — employee trends, revenue/employee, productivity ratios
3. **Utilization & Capacity** — utilization rates, capacity metrics, same-store sales
4. **Backlog & Order Book** — backlog trends, book-to-bill, order pipeline
5. **Operational Efficiency** — cost ratios, operating leverage analysis
6. **Key Metrics** — quantitative dashboard with YoY/sequential context
7. **Coverage Gaps & Citations** — data not retrievable + citation index
